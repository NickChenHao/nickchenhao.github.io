ios26+ 液态玻璃UI 适配

发表于 2026-09-28 更新于 2026-10-15 分类于 适配问题

禁用液态玻璃UI 的key 如果是27版本构建 会自动忽略
Apple Developer Documentation

自定义的Tabbar 通过 [self setValue:customTabBar forKey:@"tabBar"];设置的 也会失效或者出现各种问题

iOS 26 的 TabBar 是悬浮式设计，页面侧滑返回时，如果 TabBar 的显示状态与导航栈不一致，就可能出现 TabBar 提前显示、位置跳动或动画不协调的问题。 这需要结合 UITabBarController 和 UINavigationController 的层级来处理.

目前大多主流的层级是

这种 系统的Tabbar
如果是 push时不隐藏 没有问题
如果是 push时隐藏 hidesBottomBarWhenPushed = true 在侧滑的时候会提前出现 停止侧滑 又会隐藏

并禁止相关属性 设置为window.rootViewController

注意

  • 如果项目是通过push跳转的 目前没找到好的解决办法 只能尝试监听然后手动隐藏 或者按照苹果原生的习惯 不隐藏Tabbar
  • 如果项目是组件化 通过路由跳转的 需要统一跳转 比如TheRouter.openURL 不能直接navigationController.pushViewController 去跳转 不然会失效
